# Loan Management System

A modern Loan Management System built using JSP, Servlets, JDBC, MySQL, and Bootstrap.

## Features

- Dashboard analytics
- Add and manage loans
- Loan status tracking
- EMI Calculator
- Reports and charts
- Search and filter loans
- Activate / Close loans
- Delete loan records
- Responsive modern UI

## Technologies Used

- Java
- JSP & Servlets
- JDBC
- MySQL
- Bootstrap 5
- Chart.js
- Apache Tomcat

## Project Structure

```text
src/main/java
src/main/webapp
```

## Setup Instructions

1. Clone the repository

```bash
git clone https://github.com/raahu1l/Loan-Management-System.git
```

2. Import project into Eclipse / IntelliJ

3. Configure Apache Tomcat

4. Create MySQL database

5. Import loan_management.sql into MySQL

6. Update database credentials in:

```text
DBConnection.java
```

7. Run the project on Tomcat

## Database

The project uses MySQL database.

Run the SQL file provided:

```text
loan_management.sql
```
